Security review
---------------
- Runtime RLS proof uses a non-owner, non-superuser role without BYPASSRLS.
- Every tenant-owned Platform Core table enables and forces RLS.
- Policies use current_setting('nexora.tenant_id', true); missing context sees
  no tenant rows and cannot create tenant-owned rows.
- The context is set with set_config(..., true) inside a transaction, preventing
  pooled-connection tenant leakage.
- Composite tenant-aware foreign keys prevent cross-tenant references.
- Migration SQL creates no login role, password, or deployment credential.
- The disposable verifier generates an in-memory test password, binds only to
  loopback, uses no persistent volume, and removes its random-named container.
- The production dependency guard is now an exact allowlist containing only
  psycopg[binary]>=3.3.6,<3.4.
