IMPLEMENTED
- Exactly 19 dashboard presentation profiles with deterministic multi-role
  priority and aliases for all nine currently seeded Demo roles.
- Backend login and Demo recovery now persist issued role names, user identity,
  and expiry alongside existing permissions. A Demo-only compatibility path
  recognizes the backend-issued demo.* actor name in already-open sessions.
- Role selection affects presentation only. Each query is independently
  enabled by the exact existing backend permission, and every query key carries
  tenant/company/date context appropriate to its source.
- Role layouts define four contextual KPIs, primary/supporting analytics,
  relevant tasks/exceptions, recent activity, and unavailable source domains.
- Shared accessible charts: line/area time series, vertical/stacked/horizontal
  bars, donut, waterfall, funnel, gauge/progress, treemap, scatter, heatmap,
  and sparklines. Charts include tooltips, legends where useful, keyboard-safe
  actions, no-animation test stability, screen-reader data tables, and empty,
  loading, restricted, error, and unavailable states.
- Global dashboard controls: date range, company, assigned-role view,
  warehouse, disabled Branch/Department controls with honest missing-directory
  labels, refresh, print, and KPI CSV export.
- Drill-down links target existing authorized routes only. No dashboard action
  posts, approves, reverses, mutates, or invents a source transaction.
