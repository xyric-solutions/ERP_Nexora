NEXORA ERP NAV-03.1 - SIDEBAR / WORKSPACE LAYOUT CORRECTION
Date: 2026-08-20
Scope: shared frontend shell only

OUTCOME
=======

Corrected the desktop shell so the sidebar reserves exactly the same width as
its fixed visible panel. The working screen now consumes only the remaining
width and owns horizontal overflow for wide tables/forms. No transaction,
Finance backend, database, API, authentication or RBAC behavior changed.

ROOT CAUSE
==========

The application-specific sidebar width was previously passed to the fixed
Sidebar panel. The sibling gap that reserves desktop layout space inherited the
SidebarProvider default instead. A 21rem visible panel beside a 16rem reserved
gap therefore covered 5rem of the workspace.

IMPLEMENTATION
==============

- Moved the desktop width contract to SidebarProvider:
  clamp(16rem, 19vw, 18rem).
- Added min-w-0 to SidebarInset and the workspace content boundary.
- Added overflow-x-auto to the workspace boundary so wide module content
  scrolls within its own column.
- Added the existing SidebarRail as a desktop edge collapse control.
- Replaced the nested workspace main landmark with a div; SidebarInset remains
  the single main landmark.
- Added an authenticated shell regression using a 1600px-wide child.
