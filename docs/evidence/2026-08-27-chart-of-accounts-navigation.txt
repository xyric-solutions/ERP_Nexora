Nexora ERP - Chart of Accounts navigation correction
Date: 2026-08-27

Owner decision
- Chart of Accounts is a top-level main menu, separate from Finance & Accounting.
- Its only two current children are Nominals and Section Management.
- The correction must be available in the Demo account and must use live data.
- Long sidebar labels and their status badges must not overlap.

Implementation
- Promoted Chart of Accounts from the Finance hierarchy to a protected
  top-level menu and removed the nested duplicate from Finance & Accounting.
- Added `/finance/accounts/nominals`, filtered from the live account API to
  non-header posting accounts.
- Added `/finance/accounts/sections`, filtered from the same live account API
  to structural header accounts.
- Kept `/finance/accounts` as the complete Chart of Accounts view for existing
  dashboard links and bookmarks.
- Preserved `finance.account.read` navigation/page access and
  `finance.account.create` action visibility. No API, database, Demo seed,
  posting, journal, or permission behavior changed.
- Replaced the absolutely positioned main-menu status badge with an inline,
  fixed-width badge in the same flex row as a shrinkable/truncated label and
  chevron. Long labels retain their complete value through the title/tooltip.
