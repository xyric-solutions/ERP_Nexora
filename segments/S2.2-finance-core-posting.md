## Acceptance
- [x] Account, JournalEntry, JournalLine, Party, BankAccount, and TaxRule models follow architecture rollback rules.
- [x] Posting rejects unbalanced entries, inactive accounts, closed periods, invalid tax rules, and missing approvals.
- [x] Reversals preserve original evidence and produce balanced compensating entries.
- [x] TaxRule is jurisdiction-pluggable: `jurisdiction` selects a versioned rule pack; the posting engine never hardcodes a single country's tax logic. Pakistan is the fully-implemented reference pack for this batch (withholding tax, sales tax/GST-equivalent); additional jurisdictions add rule packs without a posting-engine rewrite. (I-009, decided 2026-08-06.)
- [x] Budget Management: versioned budgets per fiscal year/period/account/dimension, approved via the S1.3 workflow engine (not a second approval mechanism), never posted to the GL. (I-020, decided 2026-08-06 — see `docs/finance/finance-core-posting-design.md` FR-BUD-1..3.)
- [x] Recurring Journals: scheduled recurring templates generate draft journals each cycle that still pass every posting control (FR-JE-1/FR-JE-2) — recurrence never bypasses balance/period/approval checks. (I-020.)
- [x] Intercompany Accounting: mirrored due-to/due-from entries across companies post atomically (both legs or neither). (I-020.)
- [x] Consolidation structures: versioned parent/subsidiary group definitions and elimination rules are stored here; consolidated statement *output* is S2.3's responsibility, not duplicated in this segment. (I-020.)
- [x] Test expectation: unit, integration, E2E finance posting, security, performance, and migration checks, including at least one cross-jurisdiction posting test (Pakistan pack vs. a stub second jurisdiction) to prove the abstraction is not single-country-shaped.
- [x] NFR checks: trial balance variance = 0; p95 critical transaction under 2 seconds at pilot load.
- [x] Verification: `test:unit && test:integration && test:e2e && test:security && test:migration` -> expected pass.

Deep design (all posting modules, business rules, schema, API, security, testing) added 2026-08-06 at `docs/finance/finance-core-posting-design.md` (`accepted-improvements.md` I-020).
