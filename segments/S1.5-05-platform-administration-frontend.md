## Acceptance

- `/organization` renders the current tenant and organization units from live API responses and exposes create actions only with exact permissions.
- `/settings` renders fiscal calendars, accounting periods, currencies/rates, modules, policies, and numbering sequences with schema-aligned create/allocation forms.
- `/audit-log` renders immutable Platform administration audit events with correlation/hash identifiers and supported filters.
- Every request uses `web/src/lib/api/` generated types and shared client middleware; no hand-written fetch exists.
- Pagination is cursor-based; successful commands invalidate only relevant query families.
- Forms preserve entered values on failure and display canonical error message, code, correlation ID, and field details where supplied.
- Pages show honest loading, empty, forbidden, unavailable, and retry states.
- Navigation reflects exact S1.5-04 permission strings without weakening server enforcement.
- Focused behavior/accessibility tests, API drift, TypeScript/Next production build, backend regression, and real PostgreSQL regression pass.
