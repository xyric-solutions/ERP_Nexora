## Acceptance

- Production configuration is typed, validated, loaded explicitly from environment variables, and never embeds fallback credentials.
- FastAPI owns startup/shutdown and a bounded Psycopg connection pool; startup fails when PostgreSQL is unavailable.
- Liveness is process-only and readiness checks PostgreSQL with a short bounded timeout.
- Probe responses and failures never disclose the DSN, credentials, SQL, or database diagnostics.
- The existing versioned API application is mounted unchanged, preserving the canonical contract and secure defaults.
- No production composition uses legacy embedded database or in-memory business repositories implicitly.
- FastAPI, Uvicorn, and Psycopg Pool dependencies are explicit and security-allowlisted.
- Focused PostgreSQL/runtime tests and the complete backend regression suite pass.
