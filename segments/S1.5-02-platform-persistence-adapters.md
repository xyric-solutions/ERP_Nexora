## Acceptance

- Domain/services depend on a Platform repository port rather than the concrete legacy embedded database class.
- A tenant-bound Psycopg repository implements current tenant, organization, fiscal calendar, currency-rate, module, policy, and setup-draft behavior.
- Every PostgreSQL operation sets transaction-local tenant context and rejects caller/repository tenant mismatch before SQL.
- Domain errors remain safe and behavior-compatible; database diagnostics are not public error messages.
- Nested operations participate in one outer transaction and roll back completely on failure.
- JSONB, dates, exact decimals, and UTC timestamps round-trip to current domain values.
- legacy embedded database behavior and the complete backend regression suite remain green.
